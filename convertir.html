¿Para qué sirve esto?

Cuando descargues una nueva versión del Excel de KoboToolbox (con más participantes), suéltalo aquí. Se generará el archivo predictions.json con todos los pronósticos. Solo tienes que reemplazar el archivo en la carpeta data/ del repositorio y subir el cambio a GitHub.

  1. Arrastra el archivo .xlsx al recuadro (o haz clic para elegirlo).
  2. Se descargará predictions.json.
  3. Reemplaza data/predictions.json en el repositorio con el nuevo.
  4. Sube el cambio (commit + push). El sitio se actualiza solo.
